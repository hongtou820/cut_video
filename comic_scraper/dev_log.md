## 一、站点技术分析

### 基本信息
- **站点**: `https://www.18jmttios01.com/` (禁漫天堂)
- **技术栈**: Flutter Web (CanvasKit 渲染)
- **API 网关**: `www.jmttapigw.com` (备用: `www.18jmttapi01.com`, `www.jmttapi02.xyz`)
- **图片 CDN**: `txj.jxqz.top` (**图片也加密，直接下载无法打开**)
- **追踪域名**: `www.18jmttreport.xyz`

### 关键发现
1. **API 全部加密**: POST 请求体和响应体都是加密数据，无法直接调用 API
2. **CDN 图片也加密**: 通过 httpx 直接下载的图片文件是加密的，不是真正的图片
3. **Flutter Web**: 页面内容全部 canvas 渲染，不能用 HTML 解析
4. **只能用截图方式**: 由于 API 和图片都加密，只能通过 Playwright 截图获取已解密的内容
5. **游客自动注册**: 首次访问自动注册设备账号
6. **VIP 内容需要登录**: 大部分漫画需要 VIP 才能阅读，游客只能看付费页面

### API 端点 (已抓包，但加密)

## 四、版本迭代记录

### v1-v3: API 拦截尝试
- 尝试通过 `page.on("response")` 拦截图片 URL 后用 httpx 下载
- **结果**: CDN 图片加密，下载得到不可打开的数据文件

### v4-v6: 无障碍模式 + 语义定位
- 启用 Flutter Semantics 树获取文字标签
- 用标签内容定位漫画标题、tab 按钮等
- **结果**: 无障碍模式不稳定，Tab 键有时触发 Flutter 导航跳转

- **导航修复**: 用 `page.go_back()` 代替 `page.goto(BASE_URL)` 解决 Flutter SPA 路由问题
- **菜单修复**: 发现阅读器进入后菜单默认显示，不需要额外点击唤醒

## 五、当前采集流程 (v13 — 漫画名+详情页+裁剪)

```
1. 启动 headless Chromium (viewport 390x844, has_touch=true)
2. 加载首页, 等 35 秒 Flutter 初始化
3. 关弹窗: 点"再想想"(100,495) → 点"空白处关闭"(195,760) → ESC
4. 登录: #/login → 密码登录 tab → 输入手机号密码 → 登录
5. 触发教程弹窗: 进入任意漫画 → go_back() 回首页
6. 最新tab (154,71) → 点击漫画 → 进入阅读器 (#/read)
7. 菜单默认显示 → OCR 菜单栏标题 (y=5-35, x=35-180)
8. 点"详"图标 (320,25) → 进入详情页 (#/detail)
9. 截图详情页: cover.png + detail_top/mid/bottom.png
10. 点"立即阅读" (270,780) → 回阅读器
11. 逐帧截图 + 裁剪底部文字条(y≥828) + 滚动(700px) + MD5去重 (stale≥5停止)
12. 唤醒菜单→点"进度"(340,815)→点"后一话"(365,830) → 采集下一章
13. 重复 11-12 直到 MAX_CHAPTERS 章
14. go_back() 回首页 → 采集下一本
15. 保存到 downloads/{漫画名}/chapter_N/ + info.json
14. 总记录到 scrape_record_v13.json
```

## 九、关键经验总结

1. **Flutter Web 应用不能用传统爬虫**: HTML 中无数据，API 加密，图片 CDN 也加密
2. **唯一可行方案是 Playwright 浏览器截图**: 让 Flutter 自己解密渲染，我们截屏
3. **无障碍模式不可用**: Flutter CanvasKit 默认不启用语义树, "Enable accessibility" 按钮点击无效
4. **OCR 提取标题**: pytesseract + chi_sim/chi_tra 从菜单栏截图 OCR 标题最可靠
5. **纯坐标操作更可靠**: 但需要从截图中精确分析坐标
6. **弹窗是最大障碍**: 每次加载都有 2-3 层弹窗，必须先关掉
7. **VIP 是内容关卡**: 游客只能看付费页面，必须登录账号才能采集实际漫画内容
8. **Flutter SPA 导航**: `page.goto()` 对后续导航无效, 必须用 `page.go_back()` 或 Flutter 内部路由
9. **阅读器菜单默认显示**: 进入阅读器后菜单默认显示，点中央反而关闭菜单
10. **阅读器教程弹窗无法关闭**: Flutter canvas 渲染的弹窗不响应任何事件，用"牺牲进入"法绕过
11. **最新tab是3列布局**: 不是推荐页的2列, 坐标 x=70/195/320
