## 一、用户端功能

| 功能 | 说明 |

## 四、功能优先级矩阵

### P0 — 必须有（MVP）
- 女优列表页 + 搜索筛选
- 女优详情页（资料 + AI人设）
- AI聊天系统（基础对话）
- 用户注册/登录 + 年龄验证
- AI免责声明

### P1 — 应该有（V1.0）
- 社交媒体采集 + 动态时间线
- Short story 采集与翻译
- AI动图生成（20种/人）
- 会员系统 + 支付
- 收藏/关注功能

### P2 — 可以有（V1.5）
- 语音消息（TTS）
- 每日推荐 + 随机匹配
- 通知系统
- 数据分析仪表盘
- 表情包下载

### P3 — 未来规划（V2.0+）
- AI视频通话（虚拟形象）
- 用户自定义人设微调
- 女优之间的AI联动对话
- 社区功能（评论、讨论）
- 多平台客户端（iOS/Android）

## 六、API接口总览

### 女优相关
```
GET    /api/actresses          — 女优列表（分页+筛选）
GET    /api/actresses/:id      — 女优详情
GET    /api/actresses/:id/feed — 社交动态
GET    /api/actresses/:id/stories — Short stories
GET    /api/actresses/:id/gifs — AI动图列表
GET    /api/actresses/ranking  — 排行榜
GET    /api/actresses/recommend — 推荐列表
```

### 聊天相关
```
POST   /api/chat/:actressId/message — 发送消息
GET    /api/chat/:actressId/history — 聊天历史
DELETE /api/chat/:actressId/history — 清除历史
```

### 用户相关
```
POST   /api/auth/register     — 注册
POST   /api/auth/login        — 登录
GET    /api/user/profile      — 用户信息
PUT    /api/user/profile      — 更新信息
GET    /api/user/favorites    — 收藏列表
POST   /api/user/favorites    — 添加收藏
DELETE /api/user/favorites/:id — 取消收藏
GET    /api/user/history      — 浏览历史
```

### 会员相关
```
GET    /api/membership/plans   — 会员方案
POST   /api/membership/subscribe — 订阅
GET    /api/membership/status  — 会员状态
```

### 管理后台
```
POST   /api/admin/actresses       — 新增女优
PUT    /api/admin/actresses/:id   — 编辑女优
POST   /api/admin/actresses/import — 批量导入
POST   /api/admin/persona/generate — AI生成人设
POST   /api/admin/gifs/generate   — 批量生成动图
GET    /api/admin/scraper/status  — 采集状态
POST   /api/admin/scraper/trigger — 手动触发采集
GET    /api/admin/stats           — 数据统计
```
