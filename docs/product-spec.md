# AV Biu — AI女优互动平台 产品规格书

## 项目概述

基于100位真实日本人气女优，构建AI驱动的信息聚合+互动聊天平台。用户可浏览女优详细资料、查看动态内容、与AI模拟的女优人设进行对话。

---

## 目标用户

- **核心用户：** 18岁以上男性（出于合规要求，建议18+而非16+）
- **用户需求：** 了解女优信息、个性化互动体验、动态内容消费

---

## 核心功能模块

### 1. 女优资料库（Persona Database）

| 字段 | 说明 |
|------|------|
| 基本信息 | 艺名、真名（如公开）、生日、身体数据、出道日期 |
| 职业信息 | 所属事务所、作品数量、代表作品、活跃状态 |
| AI人设 | 性格标签、说话风格、兴趣爱好、口头禅 |
| 社交媒体 | Twitter/X、Instagram、TikTok、YouTube 链接 |
| 动态列表 | 自动采集的最新社交媒体动态 |

- MVP范围：**100位当前人气女优**
- 数据来源：公开信息聚合（wiki、社交媒体、公开数据库）

### 2. AI聊天系统（Chat Engine）

- 每位女优拥有独立的AI人设配置（system prompt）
- 人设基于真实公开信息 + AI生成的性格补充
- 聊天风格匹配女优的公开形象和说话方式
- **必须标注：** "AI虚构对话，非本人，仅供娱乐"
- 支持上下文记忆（单次会话内）
- 支持多语言（日语、中文、英语）

### 3. 社交媒体自动采集（Social Scraper）

- **目标平台：** Twitter/X、Instagram、TikTok、YouTube、Weibo
- **采集内容：**
  - 最新帖子/动态
  - Short story / 短视频内容摘要
  - 图片（公开内容）
- **更新频率：** 每6小时自动采集
- **展示方式：** 女优详情页的"动态"标签页，按时间排序

### 4. AI动图生成（GIF/Animation Pipeline）

- 根据女优外貌特征 + 性格标签生成动图
- **每位女优20种动图：**
  - 5种表情动图（微笑、害羞、开心、思考、惊讶）
  - 5种场景动图（日常、工作、旅行、运动、美食）
  - 5种互动动图（打招呼、再见、比心、鼓掌、眨眼）
  - 5种社交媒体风格动图（基于其社交媒体风格生成）
- 技术方案：AI图像生成 → 插帧动画 → GIF/WebP输出

### 5. Short Story 采集与展示

- 从社交媒体采集女优的短故事/日常分享
- AI翻译（日→中、日→英）
- 按时间线展示在女优详情页
- 支持用户收藏和分享

## 法律与合规

> ⚠️ **重要风险提示**

### 肖像权与公开权
- 日本法律保护个人的 **肖像権** 和 **パブリシティ権**
- 使用真实女优的名字和形象需要注意法律边界
- **建议措施：**
  - 信息展示部分使用公开可获取的数据（类似wiki）
  - AI聊天明确标注为虚构内容
  - 不使用真实照片作为AI生成内容的输入
  - 提供"本人申诉下架"机制（DMCA-like）

### 内容分级
- 平台定位为 **信息+互动**，非成人内容站
- 年龄验证：18+
- AI聊天设置内容过滤，防止生成不当内容

### 数据采集合规
- 遵守各平台 robots.txt 和 ToS
- 不采集私密/付费内容
- 采集频率合理，不对目标平台造成负担
