# Javrate 采集器 v4

## 采集目标

- **网站**: jable.tv（主采集源） + javrate.com（备用）
- **类型**: 日本有码 (censored) — 自动过滤无码和国产
- **范围**: 每日更新 + 回溯至 2024-01-01

## v4 计划 — 切换到 jable.tv 作为主采集源

### 为什么切换
- v3 流程需要 4 个站（javrate → avbase → DMM → jable.tv），太复杂
- javrate.com 有 Cloudflare 封锁，只能抓首页
- DMM CDN 需要日本 VPN
- **jable.tv 一个站就能提供所有数据**：番号列表 + 元数据 + 封面 + 剧照 + 完整视频
- jable.tv 不需要 VPN，无 Cloudflare 拦截

### v4 目标
- 直接从 jable.tv 每日更新页面采集番号列表
- 从 jable.tv 视频页面提取所有元数据（标题/演员/标签/封面/剧照）
- 从 jable.tv HLS 流下载完整视频（m3u8 → ffmpeg → mp4）
- 对比 v3 数据，确认数据完整性
- 状态：**待测试**（2026-03-18 开始）

## 采集流程

### v4 (计划) — jable.tv 直采
```
jable.tv 每日更新页面        → 番号列表 (只保留日本有码)
        ↓
jable.tv 视频详情页          → 元数据 + 封面 + 剧照 + m3u8 地址
        ↓
ffmpeg (HLS m3u8 → mp4)    → 完整视频
        ↓
保存到本地                    → downloads/{番号}/ 文件夹
        ↓
FTP 上传 → API 入库
```

### v3 — 四站联采 (当前)
```
javrate.com (Playwright)    → 番号列表
        ↓
avbase.net (HTTP JSON)      → 元数据
        ↓
DMM CDN (需要日本VPN)       → 封面 + 剧照
        ↓
jable.tv (HLS m3u8)        → 完整视频
        ↓
保存到本地 → FTP 上传 → API 入库
```

## 网络要求

### v4 (计划)
- **jable.tv** — 可直接访问（无需 VPN），一站搞定

### v3 (当前)
- **javrate.com** — 首页可直接访问，子页面被 Cloudflare WAF 封锁
- **avbase.net** — 可直接访问
- **DMM CDN (pics.dmm.co.jp / cc3001.dmm.co.jp)** — 需要日本 VPN
- **jable.tv** — 可直接访问（无需 VPN）

## 使用方式


## 已知问题

1. **avbase 404** — 新发布的番号 avbase 可能还没收录，此时只有番号和 javrate 缩略图
2. **DMM 下载失败** — 部分番号的 DMM URL 格式不同，可能下载失败
3. **Cloudflare 封锁** — javrate 子页面被封，只能从首页获取（约 30-50 个有码视频）
4. **需要日本 VPN** — DMM 的封面/剧照必须日本 IP 才能下载
5. **jable.tv 番号缺失** — 部分番号 jable.tv 可能未收录，此时回退到 DMM 预览视频
